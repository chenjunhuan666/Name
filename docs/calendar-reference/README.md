# 独立历法参考案例

本目录保存 Name V3 Phase 7 的独立日期参考。`cases.json` 中的公历/农历对应关系与 2026 年节气分钟来自香港天文台公开表，不由 `lunar-typescript` 生成，因此可用于发现固定依赖与独立来源之间的偏差。

边界如下：

- 应用输入是农历日期，因此测试核对应用输出的公历日期、展示的农历输入以及可获得的节气分钟。
- 时区固定为 `Asia/Shanghai`，与香港标准时间同为 UTC+8；1950 年香港夏令时不用于本项目输入，1950 案例只使用二月十七日正午前的日期对应关系。
- 日界固定为午夜；23:00 只进入子时，00:00 才切换自然日。
- 香港天文台表给出节气到分钟，项目依赖可能保存到秒；`boundaryToleranceSeconds: 60` 明确表示只能核对分钟级边界。
- 本文件没有独立核验八字日柱、时柱或 `EightChar sect=2` 算法。相关断言仍属于冻结依赖回归，不能描述成天文台背书。

主要来源：

- 香港天文台 1901～2100 年公历与农历对照表：<https://www.hko.gov.hk/en/gts/time/conversion.htm>
- 香港天文台 2026 年年历：<https://www.hko.gov.hk/en/gts/astron2026/almanac2026_index.htm>
