# 历法边界回归基线

2026-09-08：新增 `src/core/calendar/calendarBoundaries.test.ts` 的 16 项测试；24 个文件、117 项测试及 lint/typecheck/build 全部通过。没有修改生产算法、依赖、字库或审批记录。

## 预期依据与边界

预期日期、四柱与节气秒数来自本地固定 `lunar-typescript@1.8.6` 的离线基线采集，已写成固定断言；测试运行时不调用同一依赖生成预期。它能检测应用封装或依赖升级引入的变化，但不能发现依赖与基线共有的错误，不是独立历书或天文核验。

项目源码使用中国标准时间构造 UTC；依赖 EightChar 默认 sect=2，日柱午夜换日。晚子时的时干采用依赖自身约定，不能据时干提前变化断言日柱也在 23 时变化。地区异读、真太阳时和其他流派不在本测试范围。

## 已覆盖

- 农历 1901、2000、2026、2100 正月初一转公历及 UTC；范围外、非整数、NaN/Infinity 拒绝。
- 年份上限约束农历：2100 年腊月合法日期可以落在公历 2101 年。
- 春节前后农历年份变更，但不重复改变已过立春的年柱和月柱。
- 立春 `2026-02-04 04:02:08` 前后：输入精确到分钟，04:02 尚未交节、04:03 已交节。
- 惊蛰 `2026-03-05 21:59:00` 整分钟边界：交节时刻进入新月柱，前后节气区间更新，年日柱不变。
- 22:59、23:00、23:59、次日 00:00 的日柱/时柱与 UTC 连续性。
- 2023 普通二月与闰二月区别，以及闰月末日越界。
- 出生地点只作记录、计算不改变输入。
