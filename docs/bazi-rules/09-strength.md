# 09 旺衰五档裁决

- **规则 ID**：`bazi.strength.five-levels`。
- **规则定义**：汇总月令、季节、通根、透干、生扶与克泄耗证据，输出偏弱/稍弱/中和/稍旺/偏旺。
- **主要参考典籍**：《滴天髓》衰旺、中和资料。
- **其它佐证**：前述月令、季节、通根和生克文档。
- **流派差异**：五档分类和边界是 Name 工程模型，不是古籍统一尺度。
- **Name 采用方式**：保留支持证据和制约证据，页面可解释每个主要原因。
- **是否参与 V2**：V2.1 已实现。
- **对应代码**：`src/core/bazi/strength/strengthResolver.ts`、`evidence.ts`。
- **测试案例**：Golden Cases 同时校验档位、主要证据与 ruleId。
