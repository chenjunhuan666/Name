# 08 生扶与克泄耗

- **规则 ID**：`bazi.support-control.balance`。
- **规则定义**：同类与生我者归入支持；我生、我克、克我分别归入泄、耗、克的制约证据。
- **主要参考典籍**：《滴天髓》衰旺与生克制化资料。
- **其它佐证**：《渊海子平》十神、生克资料。
- **流派差异**：是否从势、是否成格会改变普通扶抑结论；V2.1 不实现完整格局。
- **Name 采用方式**：分类生成证据，再统一裁决。
- **是否参与 V2**：V2.1 已实现。
- **对应代码**：`src/core/bazi/strength/support.ts`、`control.ts`。
- **测试案例**：木日主中，水和木支持，火泄、土耗、金克。
