# 01 天干

- **规则定义**：十天干具有固定的阴阳与五行属性，是日主和透干分析的基础事实。
- **主要参考典籍**：《渊海子平》天干体象类资料。
- **其它佐证**：`bazi-skill/references/wuxing-tables.md` 十天干阴阳五行表。
- **流派差异**：基础属性无实质差异；体象和喜忌解读有差异。
- **Name 采用方式**：基础属性按事实表处理；体象不直接换算为分数。
- **是否参与 V2**：是，V2.1 继续使用。
- **对应代码**：`src/data/heavenlyStems.ts`。
- **测试案例**：校验甲为阳木、乙为阴木，壬为阳水、癸为阴水。
