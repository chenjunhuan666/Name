# 12 地支关系

- **规则定义**：记录六合、六冲、三合、三会、刑、害、破的结构关系。
- **主要参考典籍**：《三命通会》干支关系资料。
- **其它佐证**：`bazi-skill/references/wuxing-tables.md` 地支关系表。
- **流派差异**：刑、破的细分以及合化成立条件有差异。
- **Name 采用方式**：第一阶段只输出命中关系和 ruleId，不直接定吉凶或固定分数。
- **是否参与 V2**：V2.1 用于结构分析。
- **对应代码**：`src/data/baziRelations.ts`、`src/core/bazi/relations/index.ts`；由 `analyzeBazi()` 输出 `relations`。
- **ruleId**：`bazi.relations.branches`、`bazi.relations.breaks`。
- **实际依据**：合冲会刑害采用固定 bazi-skill 表；该表未列六破，因此六破单独登记[现代教程的六组配对](https://xuanlinyi.com/article_detail?id=301988)（2026-09-08 核查），不谎称由原表或已核验古籍条文支持。
- **完整性口径**：三合、三会要求三字齐见，不报告半合。寅巳申、丑戌未只在三字齐见时报告完整刑组，不覆盖两支刑的流派判法；子卯为两支刑。辰午酉亥自刑必须出现在不同柱，单支不自刑。不同柱重复字的各组组合分别保留，反向重复不报告。
- **解释边界**：关系可并存，如寅亥同时记录六合和六破；不裁决优先级、合化成功、吉凶或固定分数。不采用资料中的“力量减半”等数值说法；午未只记录六合，不裁决化火/化土。结构规则不是现实人生预测。
- **测试案例**：子午冲、子丑合、申子辰三合及寅卯辰三会。
