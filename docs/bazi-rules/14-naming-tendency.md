# 14 起名五行倾向

- **规则 ID**：`bazi.naming-tendency.fuyi`。
- **规则定义**：将旺衰与基础调候证据转换为“优先考虑/谨慎增加/调节方向”，不输出唯一喜用神。
- **主要参考典籍**：《滴天髓》损益中和、《穷通宝鉴》调候资料。
- **其它佐证**：Name V2 旺衰证据模型。
- **流派差异**：喜用的选取方法有扶抑、调候、格局、病药等多种体系。
- **Name 采用方式**：第一阶段实现“扶抑 + 月令季节基础调节”，禁止“缺什么补什么”。
- **是否参与 V2**：V2.1 已实现。
- **对应代码**：`src/core/bazi/strength/namingTendency.ts`。
- **测试案例**：每个五行倾向必须含有原因和至少一个 ruleId。
