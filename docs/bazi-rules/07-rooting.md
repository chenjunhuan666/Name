# 07 通根

- **规则 ID**：`bazi.rooting.evidence`。
- **规则定义**：天干在地支藏干中获得同干或同五行支持，形成得地证据。
- **主要参考典籍**：《滴天髓》根气与承载类资料。
- **其它佐证**：地支藏干表。
- **流派差异**：本气根、中气根、余气根的强度无统一数值。
- **Name 采用方式**：按角色生成不同等级的 `root` 证据，权重标明为项目模型。
- **是否参与 V2**：V2.1 已实现。
- **对应代码**：`src/core/bazi/strength/rooting.ts`。
- **测试案例**：甲见寅与甲见辰产生不同强度根气证据。
