# 13 调候

- **规则 ID**：`bazi.tiaohou.basic`。
- **规则定义**：在扶抑证据外，观察寒暖燥湿并提供基础调节方向。
- **主要参考典籍**：《穷通宝鉴》十干逐月资料。
- **其它佐证**：《滴天髓》寒暖燥湿相关资料。
- **流派差异**：调候、扶抑、格局和病药的先后有差异。
- **Name 采用方式**：V2.1 按月令输出独立基础季节结论，只把调节元素的起名倾向上调一档。
- **是否参与 V2**：已启用。
- **对应代码**：`src/core/bazi/strength/tiaohou.ts`、`src/core/bazi/strength/namingTendency.ts`。
- **测试案例**：Golden Cases 固定月令气候、调节方向、规则 ID 与来源；调候不改变扶抑旺衰分。
- **边界**：不输出唯一喜用神，也不替代十干逐月的完整调候判断。
