# 05 月令

- **规则 ID**：`bazi.month-command.priority`。
- **规则定义**：月令是时令的主要入口，优先观察，但不可脱离通根、透干和生克结构单断。
- **主要参考典籍**：《子平真诠》论用神、论用神变化。
- **其它佐证**：《滴天髓》衰旺、月令类资料。
- **流派差异**：格局法与旺衰扶抑法的用法不完全相同。
- **Name 采用方式**：生成独立月令证据，取消 V1 的单一 `+1.5` 说法。
- **是否参与 V2**：V2.1 已实现。
- **对应代码**：`src/core/bazi/strength/seasonalStrength.ts`、`evidence.ts`。
- **测试案例**：同一日主在不同月令下产生不同时令证据。
