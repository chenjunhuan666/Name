# 10 十神

- **规则 ID**：当前未发出十神 `ruleId`；本文件只登记资料与未来实现边界。
- **规则定义**：以日干为中心，按五行生克和阴阳同异推导比肩至正印十类关系。
- **主要参考典籍**：《渊海子平》十神论法。
- **其它佐证**：`bazi-skill/references/wuxing-tables.md` 十神推导表。
- **流派差异**：推导关系一致；吉凶和格局解读有差异。
- **Name 当前采用方式**：当前 V2.1 直接按五行关系产生支持、泄、耗、克的旺衰证据；不计算十神标签，不以阴阳同异区分比劫、印星、食伤、财星或官杀，也不做人生吉凶预测。
- **是否参与当前 V2 运行时**：否。五行旺衰证据不等同于十神结构解释，不能据此宣称十神已经实现。
- **对应代码**：无。`src/core/bazi/tenGods.ts` 仅为原计划中的候选路径，当前不存在且不由本次文档校正创建。
- **当前测试**：无十神测试；现有旺衰、干支关系与 Golden Cases 只覆盖已实现的五行证据和结构关系。
- **后续实现门槛**：如单独启动十神能力，需先固定日干—天干/藏干的阴阳映射、是否纳入藏干及权重、输出解释与评分边界，并增加“甲日主见甲为比肩、乙为劫财、壬为偏印、癸为正印”等独立回归案例。
