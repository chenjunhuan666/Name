# 11 天干关系

- **规则定义**：记录天干之间的生、克和五合候选关系。
- **主要参考典籍**：《渊海子平》干支论法。
- **其它佐证**：`bazi-skill/references/wuxing-tables.md` 天干五合表。
- **流派差异**：“见合”与“合化成功”不等价，合化条件的认定有差异。
- **Name 采用方式**：第一阶段只记录关系与解释，不粗暴换算成固定分数。
- **是否参与 V2**：V2.1 用于结构分析。
- **对应代码**：`src/data/baziRelations.ts`、`src/core/bazi/relations/index.ts`；由 `analyzeBazi()` 输出 `relations`。
- **ruleId**：`bazi.relations.stems`，对应固定 bazi-skill 五行/天干五合表；不把现代汇总表冒充已核验古籍条文。
- **实现边界**：只分析四柱可见天干；五合双向识别一次，生克保留施受方向。同字出现在不同柱保留各自柱位关系；跨柱匹配不等于满足相邻或合化条件。不读取藏干、不推导十神、不改变旺衰评分。
- **测试案例**：检查甲己合、乙庚合，但不默认标记“已化”。
