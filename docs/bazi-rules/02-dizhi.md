# 02 地支

- **规则定义**：十二地支记录阴阳、主五行与藏干，月支同时是季节和月令入口。
- **主要参考典籍**：《三命通会》、《渊海子平》基础干支资料。
- **其它佐证**：`bazi-skill/references/wuxing-tables.md` 十二地支表。
- **流派差异**：主五行基本一致；藏干力量和关系成立条件有差异。
- **Name 采用方式**：地支主五行用于结构展示，旺衰由多类证据综合判定。
- **是否参与 V2**：是。
- **对应代码**：`src/data/earthlyBranches.ts`。
- **测试案例**：校验子水、午火及各支藏干的完整性。
