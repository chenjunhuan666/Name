# 传统文化宝宝起名

基于 React、TypeScript 与本地确定性规则的静态宝宝起名网站。

当前已完成开发计划 Phase 1～4：项目骨架、手动四柱录入、日主与藏干解析，以及带月令权重的基础旺衰和五档起名倾向。汉字库与姓名生成将在后续阶段接入。

基础旺衰采用透明的 V1 启发式模型：表层干支每项计 1、藏干每项计 0.5、月令主五行额外计 1.5，再按日主的同类与生扶占比划分偏弱、中和、偏旺。该结果用于候选字筛选，不代表完整命理定论，也不会把“五行缺失”直接等同于“必须补入姓名”。

## 本地运行

```bash
pnpm install
pnpm run dev
```

## 验证

```bash
pnpm run test
pnpm run lint
pnpm run typecheck
pnpm run build
```
